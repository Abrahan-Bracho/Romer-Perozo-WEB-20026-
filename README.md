# Romer Perozo · Landing page

Base local de una landing page estática en español. Abre `index.html` en un navegador para verla. No requiere instalación ni backend.

## Archivos

- `index.html`: portada, presentación, trayectoria, enseñanza, miembros a nivel mundial y galería.
- `styles.css`: diseño adaptable con negro, blanco y rojo inspirados en el logo de Perozo Method Kenpo.
- `script.js`: menú móvil y ampliación de fotografías.
- `assets/`: copias de las cuatro fotografías suministradas logo de la organización y favicon.

## Contenido pendiente

Se incorporó el texto suministrado por el usuario: inicio en 1991, más de 34 años de experiencia, seis grados, cinco cursos/seminarios y formación en instrucción para distintas edades y personas con discapacidad. Se mantienen las denominaciones de disciplinas y grados proporcionadas, con ajustes de mayúsculas y redacción. Se usa Perozo, coherente con el logo suministrado. Pendiente añadir datos de contacto cuando sean suministrados.

La sección de miembros incluye España, México y Venezuela. Las tarjetas están preparadas para incorporar los nombres, ciudades y fotografías de los miembros cuando se suministren.

Identidad actualizada con el logo suministrado: rojo como acento principal, títulos de mayor peso y emblema visible en cabecera, portada y pie. El archivo original se conserva; CSS encuadra el emblema para ocultar los márgenes de la captura.

Botón de WhatsApp fijo en la esquina inferior derecha, con el número proporcionado por el usuario y un mensaje inicial sobre clases. Funciona también sin JavaScript con su enlace directo.

## Reemplazar la biografía

Abre `biografia.js` y reemplaza el contenido de `texto` entre las comillas invertidas. Separa los párrafos con una línea vacía y cambia `provisional` a `false` para quitar la etiqueta de borrador. La biografía se muestra como texto, sin interpretar HTML. La foto del maestro es `assets/foto-4.jpeg`, en una sección de fondo blanco.

La cabecera permanece visible al desplazarse. Los enlaces internos dejan espacio para que los títulos no queden detrás del menú; en móvil se conserva la navegación desplegable.

Cada tarjeta de país incluye un ícono de persona, un espacio para el nombre y una descripción provisional del representante. Sustituir estos marcadores y el ícono cuando se reciban nombres, biografías y fotografías reales.
